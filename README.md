# AuthApplicationReactNative

## 🎯 Projenin Amacı
Bu proje, React Native ve Expo kullanılarak geliştirilmiş, kullanıcı kimlik doğrulama (authentication) süreçlerini yöneten kapsamlı bir mobil uygulamadır. Uygulama içerisinde kullanıcı kayıt, giriş (login) ve oturum yönetimi gibi temel işlemler yer almaktadır.

Proje, modern mobil uygulama standartlarına uygun olarak tasarlanmış olup; durum yönetimi için Redux Toolkit, veri kalıcılığı için Async Storage ve ağ istekleri için Axios kütüphanelerini kullanmaktadır. Kullanıcı deneyimini iyileştirmek adına React Navigation ile yapılandırılmış bir ekran geçiş sistemine sahiptir.

## 🛠️ Kullanılan Teknolojiler
*   **Framework:** React Native, Expo (v52)
*   **Dil:** JavaScript
*   **Durum Yönetimi:** Redux Toolkit, React-Redux
*   **Navigasyon:** @react-navigation/native, @react-navigation/native-stack
*   **Veri Kalıcılığı:** @react-native-async-storage/async-storage
*   **HTTP İstemcisi:** Axios
*   **Derleyici:** Babel

## 🚀 Kurulum ve Çalıştırma

Projeyi yerel ortamınızda çalıştırmak için aşağıdaki adımları izleyin:

1. **Depoyu Klonlayın:**
   ```bash
   git clone <repo-url>
   cd AuthApplicationReactNative
   ```

2. **Bağımlılıkları Kurun:**
   ```bash
   npm install
   ```

3. **Projeyi Başlatın:**
   Expo kullanarak projeyi ayağa kaldırın:
   ```bash
   npm start
   ```

4. **Platform Seçimi:**
   *   **Android için:** `npm run android`
   *   **iOS için:** `npm run ios`
   *   **Web için:** `npm run web`

# AuthApplicationReactNative

## 🎯 Project Purpose
This project is a comprehensive mobile application developed using React Native and Expo, designed to manage user authentication processes. It encompasses core functionalities such as user registration, login, and session management.

The project follows modern mobile development standards, utilizing Redux Toolkit for state management, Async Storage for local data persistence, and Axios for handling API requests. It features a structured navigation system using React Navigation to provide a seamless user experience.

## 🛠️ Technologies Used
*   **Framework:** React Native, Expo (v52)
*   **Language:** JavaScript
*   **State Management:** Redux Toolkit, React-Redux
*   **Navigation:** @react-navigation/native, @react-navigation/native-stack
*   **Data Persistence:** @react-native-async-storage/async-storage
*   **HTTP Client:** Axios
*   **Compiler:** Babel

## 🚀 Installation and Setup

Follow these steps to run the project in your local environment:

1. **Clone the Repository:**
   ```bash
   git clone <repo-url>
   cd AuthApplicationReactNative
   ```

2. **Install Dependencies:**
   ```bash
   npm install
   ```

3. **Start the Project:**
   Start the application using Expo:
   ```bash
   npm start
   ```

4. **Run on Platform:**
   *   **For Android:** `npm run android`
   *   **For iOS:** `npm run ios`
   *   **For Web:** `npm run web`
